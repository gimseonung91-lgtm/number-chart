# 수 배열표 놀이

자폐성장애·지적장애 학생이 수의 기초 개념과 1~100 수 배열표를 익히는 웹앱이에요.
글을 읽지 않아도 할 수 있도록 손가락 시범, 그림 지시, 신경망 음성으로 안내해요.
자폐성장애 학생을 위한 **SCERTS 모델**(사회 의사소통 · 정서 조절 · 교류 지원)에 맞춰, 학생이 그림 버튼으로 '도와주세요'·'쉬고 싶어요'를 요청하고(쉬기는 '쉬기 카드'와 '먼저 몇 문제 → 그다음 쉬기'로 남발을 막아요), 기분을 고르고, 선생님과 함께 보며 기뻐하는 순간을 넣었어요. 자세한 내용은 선생님 메뉴 → 설정 → 'SCERTS 모델로 본 이 앱'에 있어요.

## 쓰는 방법

- **컴퓨터**: `index.html`을 더블클릭하면 크롬이나 엣지에서 열려요. 인터넷이 없어도 동작해요(글꼴만 기본 글꼴로 바뀌어요).
- **태블릿**: 아래 '깃허브 페이지로 올리기'로 주소를 만든 뒤, 태블릿 브라우저에서 그 주소를 열어요.
- **선생님 메뉴**: 오른쪽 위 `선생님` → 버튼을 2초 동안 누르고 있기 → 학습지 인쇄, 학습 기록, 설정.
- **학습지 인쇄**: 선생님 메뉴 → 학습지 인쇄 → 놀이를 고르고 `인쇄하기`. 용지는 A4로 맞춰 주세요.

학습 기록과 설정은 앱을 연 기기의 브라우저에 저장돼요. 태블릿 기록은 태블릿에서 확인해요.

## 놀이 8가지

| 순서 | 놀이 | 익히는 것 |
|---|---|---|
| 기초 1 | 하나씩 세어 보기 | 일대일 대응, 기수의 원리, 수의 보존 |
| 기초 2 | 한눈에 보기 | 즉각적 인지, 5와 10의 구조 |
| 기초 3 | 블록 계단 | 1 큰 수, 1 작은 수 |
| 기초 4 | 10 묶음 | 몇십 몇 (십진기수법) |
| 배열표 | 수 배열표 채우기 | 1~100의 차례 |
| 배열표 | 이웃 수 찾기 | 왼쪽·오른쪽 1, 위·아래 10 |
| 배열표 | 더 큰 수, 더 작은 수 | 크기 비교 |
| 배열표 | 수 이어가기 | 1씩, 10씩 뛰어 세기 |

## 깃허브 페이지로 올리기

1. 깃허브에서 새 저장소를 만들고 [업로드 안내](깃허브_올리기_안내.md)의 파일 목록에 따라 올려요. 브라우저에서 직접 올릴 때는 `.gitignore`가 파일을 걸러 주지 않으므로 필요한 파일만 골라요.
2. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 배포가 끝나면 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열려요. 반영에는 최대 10분 정도 걸릴 수 있어요([GitHub 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)).

`audio/clips.js`는 약 12MB예요. 브라우저 업로드의 파일당 25MiB 제한보다 작아요([GitHub 공식 안내](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)).

## 수 개념 지도 참고 문서

[수 개념 지도 메모](<수학 1정연수 참고자료.md>)에는 앱의 학습 목표와 활용 방법을 새 문장으로 정리했어요. PDF나 이미지 없이 읽을 수 있으며, 앱의 실행에 필요한 파일은 아니에요.

원본 PDF, 그림 62장과 이미지 목록, 원문을 옮긴 기존 Markdown은 공개 파일에서 제거했어요. 같은 이름의 현재 Markdown은 앱 설명용으로 다시 작성한 문서예요. 관련 원본을 다시 보관할 때는 이 앱 폴더 밖에 두어요.

## 폴더 구성

```
index.html          화면 틀
css/app.css         화면 모양 (태블릿 맞춤 포함)
css/sheets.css      A4 학습지 모양과 인쇄 규칙
js/core.js          공용 도구, 설정, 효과음, 그림
js/speech.js        목소리 (녹음 조각 재생, 없으면 기기 목소리)
js/modes.js         놀이 8가지 (문제, 화면, 말, 힌트, 시범 순서)
js/scerts.js        SCERTS 화면: 기분 묻기, 쉬는 곳(숨쉬기), 함께 보기
js/play.js          놀이 진행, 손가락 시범과 안내, 태블릿 처리
js/print.js         학습지 8종
js/app.js           화면 전환, 선생님 모드, 설정, 기록
audio/clips.js      신경망 음성(ko-KR SunHi) 조각 748개
tools/              점검과 음성 만들기 도구
```

## 고친 뒤 점검하기 (node 필요)

```
node tools/check.js
```

모든 설정 조합에서 문제를 7만여 개 만들어 정답, 보기, 음성 조각이 맞는지 확인해요.

말하는 문장을 바꿨다면 음성 조각을 다시 만들어요 (python과 `pip install edge-tts` 필요).

```
node tools/voice_units.js > tools/units.json
python tools/make_voice.py
```
